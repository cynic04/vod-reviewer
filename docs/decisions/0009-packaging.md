# 0009 - Package for Windows with electron-builder

## Context

Running the app meant opening a terminal in the repository. It should be installable like
any other program: a desktop shortcut, a Start menu entry, its own icon.

## Decision

- **electron-builder** produces an NSIS installer (`npm run package` ->
  `dist/VOD-Reviewer-Setup-<version>.exe`). The install is one-click and per-user, so it
  needs no administrator rights, and it creates desktop and Start menu shortcuts.
- **Only `out/` and `package.json` are shipped.** The renderer is fully bundled by Vite,
  so React, the router and zustand are `devDependencies`; the only runtime dependency
  left in the package is `zod`, used by the main process.
- **The icon is Millia Rage's portrait**, generated by `npm run make:icon` into
  `build/icon.ico` (executable, installer, shortcuts) and `resources/icon.png` (window
  icon when running unpackaged). The script takes any character id, so changing the icon
  is one command: `npm run make:icon -- sol`.
- **The data folder is pinned** to `%APPDATA%\vod-reviewer`. Electron would otherwise
  derive it from the display name, giving the packaged app ("VOD Reviewer") a different,
  empty library from the development build.
- The app sets its AppUserModelID to the installer's `appId` so a taskbar pin groups with
  the running window.

## Consequences

- The installer is about 120 MB; almost all of it is the Electron runtime.
- **The build is not code-signed.** Windows SmartScreen will warn the first time the
  installer runs ("More info" -> "Run anyway"). Fine for a personal tool; signing needs a
  certificate if the app is ever distributed.
- There is no auto-update: installing a newer build over the old one is the upgrade path,
  and it keeps the library. Uninstalling also leaves `%APPDATA%\vod-reviewer` in place.
- The development build and the installed app share one library, and only one of them can
  run at a time (single-instance lock).
- The packaged app is covered by the same end-to-end test as the development build (set
  `VOD_REVIEWER_E2E_EXECUTABLE`).
- The icon is ARC SYSTEM WORKS artwork; the caveat in ADR 0007 applies to it too.
